任务状态机

叶子存储两个布尔：done 和 voided。父任务不存自己的状态；它的 done 和 voided 分别由直接子项归约出来，动作全部完成后逐层重算。

当前实现

1. 叶子是唯一的状态载体

叶子状态 = done（false / true）× voided（false / true），共四个状态。下面四个圆角框是全部状态。

2. 父任务的状态也是两个布尔

父任务不存自己的状态字段。动作全部结束后，每个父任务只读取直接子项的 done 和 voided，分别归约出父任务的 done 和 voided。

输入：直接子任务的两个布尔

每个直接子项的 done / voided 分别参与父任务的归约。

A · done=false, voided=false B · done=true, voided=false C · done=false, voided=false
→

输出：父任务的两个布尔

两个归约结果组合成父任务状态；示例结果为 Open。

done=false voided=false → Open

记 closed(c) = done(c) || voided(c)。父任务的两个字段分别归约；false 条件就是 true 条件的取逆。

父任务字段 为 true 的条件 为 false 的条件（true 的取逆）
done (∃ c：done(c)=true) ∧ (∀ c：closed(c)=true) ¬[(∃ c：done(c)=true) ∧ (∀ c：closed(c)=true)]
等价于 (∀ c：done(c)=false) ∨ (∃ c：closed(c)=false)
voided ∀ c：voided(c)=true ¬(∀ c：voided(c)=true)
等价于 ∃ c：voided(c)=false

父任务完成要求：至少一个直接子任务完成，并且没有未关闭的直接子任务。作废子项不会阻止父任务完成；只要求所有子项都已关闭，且至少有一个真正完成。

父任务显示状态由 (done, voided) 组合决定，对应关系见第 1 节的状态表。父任务没有子任务时就不是父任务，不在这张归约表内。

责任边界：动作只修改叶子和树结构；所有动作完成后，从叶子向上逐层归约。父任务只读取直接子项的 done 和 voided，不读取孙任务，也不在动作中途推导。

3. 动作表：一次动作可以改变多个条目

模块级状态 = 叶子状态 + 树结构。动作只修改叶子和结构；动作全部完成后，父任务逐层重算。

动作作用对象效果
TOGGLE叶子任务未作废时 done = !done；作废时自环。父任务重算。
VOID任意任务递归把该任务子树的所有叶子 voided=true；父任务重算。
RESTORE任意任务递归把该任务子树的所有叶子 voided=false；父任务重算。
ADD未作废的父任务下新增 done=false, voided=false 的叶子；完成或未完成的父任务都可以新增。作废父任务下拒绝新增。父任务重算。
INDENT任务改变父子关系；不能缩进到作废任务下。完成/未完成父任务都允许，父任务重算。
MOVE象限顶层任务整棵子树移到同周另一个象限；子树状态原样保留。
OUTDENT子任务提升一层，不改任务自身状态；父任务重算。
DELETE任意任务删除整棵子树；靠撤销恢复，父任务重算。
UNDO / REDO整篇文档文档快照回滚；不属于状态机迁移。

父任务的菜单“作废/恢复”在状态机里就是一次 VOID / RESTORE 动作分发到整棵子树，不是父任务节点的独立迁移。

5. 落盘

落盘表示

  • 叶子：done: boolean + voided: boolean，两个字段都存。
  • 父任务：不存 done，也不存 voided；两个值都由直接子项归约。
  • 四个叶子状态由 (done, voided) 组合得到，父任务只是同样的组合结果。

周继承

  • 顶层 done || voided 的任务整棵不带入新周。
  • 未关闭的顶层任务保留整棵子树，包含已完成或作废的子项。

为什么这样落盘：叶子的完成和作废本来就是两个独立布尔，直接存 done 和 voided，不需要字符串枚举。父任务的两个布尔是归约结果，落盘会产生第二份真相，所以父任务不存状态字段。
