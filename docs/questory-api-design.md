# Questory 外部 API 设计

## 能力边界

| 能力 | 接口 | 状态 |
|---|---|---|
| 读取一周的全部内容 | `GET /api/weeks/{week}` | 已实现 |
| 新增或编辑已有周的总结 | `PUT /api/weeks/{week}/review` | 设计中，未实现 |

任务的新增、编辑、删除、完成、作废、移动和排序均属用户界面范围，不开放给 agent。周标题、周备注、假期状态和整份文档也不提供给 agent 写入。外部接口不建周，不提供周列表或批量操作。

现有 Web 界面通过 `/api/doc` 和 `/api/rollover` 管理文档和周继承；它们不属于 agent 接口。本机 Host 与请求来源校验不区分 agent 与其他本机调用方。这份设计限定对 agent 提供的接口，不能隔离拥有本机 shell 或文件访问权限的 agent。若部署要求强制隔离，须在发布写能力前限制 agent 访问 UI 写入口及数据文件。

## 周定位

- `current`：覆盖今天的已记录周，按 Questory 的日历（`Asia/Shanghai`）匹配。
- 周标题：界面上显示的标题，例如 `2026 11.16-11.22`，传入时按 URL 规则编码。

不存在时返回 404，不回退到其他周，也不创建记录。内部周 ID 不是公开参数。

## `GET /api/weeks/{week}` — 读取整周

成功返回 `text/markdown; charset=utf-8`。一次包含周标题、假期标记（如适用）、周备注、各象限的完整任务树与任务备注、周总结原文。保留任务顺序和层级；状态复用界面派生逻辑，标为「未关闭」「已完成」「已作废」，作废优先。状态只反映当前记录。

不拆分视图，不分页，不返回内部 ID，不生成统计或进展判断。查询参数不受支持（400）；目标周不存在（404）；读取或文档校验失败（500）。

```bash
curl -fsS http://127.0.0.1:5199/api/weeks/current
curl -fsS 'http://127.0.0.1:5199/api/weeks/2026%2011.16-11.22'
```

## `PUT /api/weeks/{week}/review` — 新增或编辑周总结（未实现）

提交 JSON `{"review":"总结正文"}`，仅接受这一字段。已有周未填写总结时新增，已填写时替换全文。不接受空白正文，不提供清空总结的操作。普通周和假期周都可填写总结，与界面一致。成功返回 204；输入不合法返回 400，目标周不存在返回 404。

实现时复用界面的 `setReview` 和服务端串行写盘：在队列内读取最新文档、定位周、应用总结修改并保存。保存不能改动任务、周备注或其他周；外部编辑也要和浏览器的保存冲突处理兼容。验收覆盖新增、编辑、拒绝空白及额外字段、缺周不创建，以及写前后除目标周 `review` 外内容完全一致。
